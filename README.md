## ✨ Features

- Basic calculations — addition, subtraction, multiplication, division
- Expression display showing full calculation like `1 + 5 =`
- Percentage and plus/minus support
- Clean dark theme UI
- Watermark — Developed by Akshay Palampalle

---

## 📲 How to Install

1. Download the APK file from this repository
2. Transfer it to your Android phone
3. On your phone go to **Settings → Install unknown apps** and enable it
4. Open the APK file and tap **Install**
5. Done! The app is ready to use
